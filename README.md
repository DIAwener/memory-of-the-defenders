Письма с фронта
Веб-приложение для чтения исторических военных писем с фильтрацией и возможностью оставлять ответы. Чистый JavaScript, адаптивный дизайн, локальное хранение данных.
Структура
    index.html - основная страница с семантической разметкой
    styles.css - адаптивные стили в пергаментной цветовой гамме
    script.js - логика приложения: фильтры, случайный выбор, ответы
Функции
     Случайный выбор писем из предзагруженного архива
     Фильтрация по году, фронту и роду войск
     Ответы пользователей с сохранением в localStorage
     Адаптивный дизайн для мобильных и десктоп
Технологии
    HTML5 (семантические теги, dialog)
    CSS3 (Grid/Flexbox, переменные, медиазапросы)
    Vanilla JavaScript (ES6+, LocalStorage, DOM API)
Данные
    Письма: статический массив с метаданными
    Ответы: динамическое хранение в браузере
    Фильтры: уникальные значения из архива писем
